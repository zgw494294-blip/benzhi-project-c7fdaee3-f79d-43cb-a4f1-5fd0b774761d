# 口述史公开授权工作台

本项目面向地方文化机构，在口述史素材公开前完成一条有状态的治理流程：整理员创建访谈包并登记知情同意边界，逐段标注敏感性并提交脱敏修订；伦理复核员给出通过或退回整改结论；开放负责人核对后冻结公开清单，并签发可现场校验摘要的公开授权凭据。

工作台支持有序片段批量录入和原子批量判定，并实时汇总待判定、各公开结论、风险标签和限制期限；脱敏修订按版本永久追加，可查询历史和相邻版本对照。伦理复核员可从待复核队列查看轮次进度并批量裁决。开放负责人必须先生成只读冻结清单预览，再以预览摘要确认批准；预览不会改变聚合版本、事件时间线或凭据序号。

工作台不是通用内容管理系统。它只处理访谈包从草稿到公开授权的闭环，冻结后的同意记录、片段顺序和公开文本不能再修改。

## 构建

```text
go build ./cmd/server
```

## 运行

默认只监听高位回环地址 `127.0.0.1:19081`，数据写入 `./data`：

```text
go run ./cmd/server
```

可显式设置监听地址和数据目录：

```text
go run ./cmd/server -addr=127.0.0.1:19091 -data=./data
```

也可通过 `PORT` 环境变量提供端口号；服务仍绑定 `127.0.0.1`。为避免意外暴露人工治理资料，`-addr` 会拒绝非回环地址。浏览器访问服务根路径即可使用工作台。

执行真实 HTTP 全流程自检后自动退出：

```text
go run ./cmd/server -addr=127.0.0.1:19081 -selfcheck
```

## 测试

```text
go test ./...
```

测试覆盖领域状态机、批量操作原子失败和排序、判定与复核进度、修订历史及固定整改闭环、冻结预览摘要与凭据校验、乐观并发和幂等重试、事件日志重启恢复及截断检测，以及 HTTP 页面与请求限制。

## 持久化与并发

写操作必须携带 `expectedVersion`、`idempotencyKey`、`actor` 和匹配动作的 `role`。服务在单写入锁中校验聚合版本，重复的同一幂等请求返回首次结果，不产生重复事件；同一幂等键对应不同请求时返回冲突。

本地 `events.bin` 使用长度前缀帧，包含递增序号、前序摘要和校验和；`snapshot.json` 通过临时文件同步后原子替换。启动恢复会验证完整事件链，并拒绝截断、篡改或与快照不一致的数据。冻结清单、凭据及审计事件在一次提交边界内生成。

## 主要 JSON 入口

- `POST /api/packages/{id}/segments/batch`：批量录入有序片段。
- `POST /api/packages/{id}/classification/batch`：批量提交片段风险判定。
- `GET /api/packages/{id}/segments/{segmentID}/revisions`：查询不可覆盖的修订历史；`revisions/compare?from=1&to=2` 对照相邻版本。
- `GET /api/review-queue` 与 `POST /api/packages/{id}/review/batch`：查询待复核队列并批量裁决。
- `GET /api/packages/{id}/release/preview`：生成只读冻结预览；批准请求需携带返回的 `manifestDigest` 作为 `previewManifestDigest`。
